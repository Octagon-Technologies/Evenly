Same spot, in red. The name stays in the field so nothing is retyped. The same bar covers an empty field ("Type their name first") and a name already in the group ("Tyler is already in this group"), which is refused, not added.

One thing to know about errors. Adding someone saves on the phone first and reaches the server later, so being offline is not an error. Tyler is added straight away and syncs when the connection is back. The red bar is only for a save that really failed on the device (rare) or an empty name. Showing "no connection" on a save that actually worked would make people add the same person twice, which is exactly what the green bar is meant to prevent.
Decided (2026-11-24).
  • After an add, the field clears and the keyboard stays up for the next name.
  • A name already in the group (ignoring case and spaces) is blocked with the red bar.
  • The newest person shows at the top of this page's list, tinted green for 3 seconds.
  • Group settings' "Add member" pop-up is removed. Adding by name lives only on this page.

How the pages move

  • Members → a page: slides in from the right, Members slides out to the left.
  • Back: the reverse.
  • The sheet frame, grabber and the page behind stay still the whole time.
  • Add new member grows taller than Members (the keyboard takes the bottom). QR stays at Members' height.
