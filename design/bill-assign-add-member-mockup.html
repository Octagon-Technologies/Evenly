B. Recommended: one field that searches and creates

Same sheet, but the top field does double duty. Empty, it shows the group members not yet on the bill (one tap adds). Type, and it filters that list; if nothing matches exactly, the top row becomes Create "Mar" with the blue button. No explanation copy, no separate "new member" mode, and it naturally prevents a duplicate "Kev" when the real Kev is already in the group.

Edge cases. No group (one-time split) or everyone in the group is already on the bill: the sheet is just the field, and anything typed shows only the Create row. Exact name match (typing "Kev" when Kev is in the group): no Create row, so you can't make a duplicate by accident; if two different people really share a name, the user types "Kev 2". Multi-serving items ("Assign each serving") get the same sheet from the servings screen.
